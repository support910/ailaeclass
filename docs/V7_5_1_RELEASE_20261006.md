# AiLAEClass v7.5.1

Date: 2026-10-06.

## Scope

Only the legacy course exercise ViewMode changes behavior. Traditional exams,
quick practice, course content, existing results, authentication, payments,
AI providers, permissions and database schema are not modified.

Fixes: revisiting correct answers no longer disables Next permanently; a pending
advance timer prevents duplicate clicks and is cancelled on teardown; restored
progress is evaluated only after the correct questionnaire finishes loading.
Incorrect answers receive localized retry feedback in 15 UI languages.
