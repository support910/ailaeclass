# Ailaeclass v7 Update - 2026-07-14

## Release Scope

This update improves course cover management and expands the interface language options while preserving the existing administrator, teacher, student, exam, course, feedback, and simulation workflows.

## Course Covers

- Course creation now includes a cover picker with curated default images and custom image upload.
- Course settings allow administrators and teachers to replace the current cover.
- Default images are previewed before the user confirms the change.
- Custom images are previewed locally before upload and are uploaded only after confirmation.
- Resetting a course cover requires explicit confirmation and supports cancellation without changing the current cover.
- Custom cover uploads use the protected server upload route and the dedicated public `course-covers` storage bucket.
- Course cards, learning pages, public previews, join-course pages, audience pages, and course landing pages use the same cover fallback logic.
- Unsplash search, its API route, and its client dependency were removed.

## Languages And Guides

- Added Bahasa Melayu (`ms`).
- Added Bahasa Indonesia (`id`).
- Added Thai (`th`).
- Added localized feature-guide content and guide target matching for the three new languages.
- Added English fallback behavior for untranslated strings.
- Updated course creation and course-cover text in English, Simplified Chinese, Traditional Chinese, Malay, Indonesian, and Thai.

## Safety And Validation

- Course cover URLs are validated before course creation.
- JPG, PNG, and WEBP uploads are limited to 5 MB.
- Local image previews use CSP-compatible data URLs so selected images appear immediately without a refresh.
- Canceling default selection, custom upload, or reset leaves the current cover unchanged.
- No database schema migration is included in this update.
