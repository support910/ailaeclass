# AiLAEClass v7.5.0

日期：2026-09-22。發佈目標：既有 Railway `attractive-harmony / ailaeclass / production` 與 Supabase `kiqzanfkpivkuvlvxqsp`。

## 更新內容

- 學生入口：「模擬系統 → 分享給教師」。選擇已加入課程，提交成績截圖 Google Drive 連結；實飛可同時提交影片，同次飛行只建一筆紀錄。
- 管理員入口：「模擬系統 → 學生提交」。可按課程篩選、查看學生姓名、飛行名稱、科目、時間、說明，並開啟原始圖片／影片連結。
- 教師同樣有「學生提交」，但只可查看自己獲分配管理課程的紀錄；其他學生及其他機構不可查閱。
- 提交包含明確分享同意、成功提示、重試去重、限流；學生可確認後撤回，之後教師及管理員不可從此模組讀取。
- 「我的成績」新增私人飛行分析與歷史，可分析圖片、取樣影片及 CSV／JSON／Google 試算表，同次實飛的圖片與影片可合併比對。
- Chatbot、Agent 與 AI 工具統一使用 Kimi；原知識庫、語言選擇、回答長度差異保持不變。
- 新增介面覆蓋繁中、簡中、英文、馬來文、印尼文、泰文、印地文與手機佈局。

## 功能界線

分享連結不等於授予 Google Drive 存取權。學生須自行向相關教師授權；撤回本系統分享不會撤銷 Drive 權限或收回已下載副本。

個人 AI 報告不自動分享給教師。分享紀錄標示「未評分」，穩定 submission ID 預留給後續正式評分。影片僅取樣影格，不分析音訊、不認證身分、防作弊或飛行安全，AI 建議不是正式成績。

本次使用已驗證可用的 Kimi Code API 設定；商業產品的方案、配額及適用條款仍須由帳戶持有人確認，建議正式採購 Kimi 開放平台服務。密鑰只放 Railway 私有環境變數，不放前端或 Git。
