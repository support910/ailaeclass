# AiLAE Class 更新日志 - 2026-08-03

## 新增功能

- 新增管理员专属「数据驾驶舱」，集中展示学生、教师、课程、活跃用户、课程完成率、考试通过率与近期平台记录。
- 新增活动趋势、角色分布、课程状态、考试模式、课程参与度等图表，并支持 7、30、90 天时间范围。
- 新增 CSV 数据导出；导出记录使用匿名账号标识，避免暴露用户邮箱和原始身份信息。
- 新增隐私与审计记录，包括访问结果、风险等级、资源类型、数据保留期限和网络标识哈希。
- 全球鹰手册内容加入 AiLAE Agent 与 Chatbot 的知识库，不替换原有课程、考试和操作手册知识。
- 新增支付中心、FPS 人工核验流程、支付订单审计与私有收据存储。
- 新增课程营销漏斗页面、线索、事件、自动化流程和订单基础模块。

## AI 回答策略

- Chatbot 调整为简短回答模式，适合快速操作咨询。
- 复杂问题会提示用户转到 AiLAE Agent 获取更完整的说明。
- AiLAE Agent 使用更高的回答长度上限，适合手册、课程和复杂专业问题。
- AI 审计仅保存经过清理的元数据，默认不保存用户原始提问和回答正文。

## 安全与权限

- 数据驾驶舱入口及 API 仅对 `admin@5gnu.com` 超级管理员开放。
- 教师和学生端不显示数据驾驶舱，携带有效教师令牌访问 API 仍会被拒绝。
- 支付收据存储桶设为私有，限制文件大小为 5 MB，仅允许 JPEG、PNG、WebP 和 PDF。
- 支付回调加入签名、时间窗口、金额和订单状态校验，防止伪造、重放和重复处理。
- Supabase 迁移历史已与生产数据库对齐，避免后续部署重复执行旧迁移。
