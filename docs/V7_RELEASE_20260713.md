# Ailaeclass v7.0.0 - 2026-07-13

## Release Scope

This release advances the existing three-role system: administrator, teacher, and student. It preserves the frozen v6 baseline and deploys only to the existing Railway service and Supabase project.

## Course Management

- Teachers can create courses again.
- Administrators can assign one or more teachers to a course.
- Administrators can add or remove students and change course teachers.
- Assigned teachers receive course management permission.
- Teacher dashboards no longer show the earnings section.
- Teachers and students can browse courses they have not joined and inspect the public overview without seeing learning materials.
- Students can favorite and unfavorite courses.

## Course Explore And Applications

- The Explore course detail page now highlights learning outcomes, course strengths, structure, and instructors.
- The obsolete "not accepting students" message and pricing-oriented flow are removed from the in-app preview.
- The back button always returns to Explore.
- Students can apply to a course directly from the preview.
- Submitted applications remain pending and do not automatically enroll the student.
- Teachers see applicant name, email, submission time, and total count in Members.
- The application list is informational only; there are no approve or reject controls.

## Feedback Center

- Administrator, teacher, and student sidebars include Feedback.
- Users can submit issue location, description, occurrence time, page/port, and screenshots.
- Only `admin@5gnu.com` can access the review queue and protected screenshots.
- Unread and resolved states are visually separated.
- Feedback screenshot previews use CSP-compatible data URLs and render without a refresh.
- Successful submission displays a visible confirmation next to the submit button.

## Student Exam Navigation

- Student exam pages include a reliable return action to the previous course exam list.

## Database

- `20260711000000_course_favorites.sql` creates protected course favorites.
- `20260713000000_user_feedback.sql` creates the server-mediated feedback table.
- Existing `course_join_request` storage is reused for course applications; no broad schema replay is required.

## Verification Completed

- Production dashboard build completed successfully.
- Student course application persisted after refresh.
- Teachers could see the pending applicant in Members.
- Applying did not automatically enroll the student.
- Teacher Members contained no application approval or rejection controls.
- Feedback screenshot authorization and rendering were verified.
