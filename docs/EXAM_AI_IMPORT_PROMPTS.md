# 考试题目 AI 生成与 CSV 导入提示词

这个文件给老师复制到 ChatGPT、DeepSeek、Kimi 等 AI 工具中使用。建议一次生成 10-20 道题；数量更多不会降低系统解析准确度，但会增加人工检查题目、答案、图片链接的时间。

## 通用提示词

```text
请帮我生成一份可以导入 ailaeclass 考试系统的 CSV。

要求：
1. 第一行必须是表头。
2. 每次生成 20 道以内。
3. 支持题型：单选题、多选题、判断题、问答题。
4. CSV 表头固定使用：
题型,题目,题目图片,选项A,选项A图片,选项B,选项B图片,选项C,选项C图片,选项D,选项D图片,选项E,选项E图片,答案,分数,答案解析
5. 单选题答案写 A/B/C/D/E。
6. 多选题答案用英文分号分隔，例如 A;C;D。
7. 判断题答案可以写 对/错，也可以写 A/B，但选项A应为“对”，选项B应为“错”。
8. 问答题可以不填选项和答案，但必须填写答案解析或参考要点。
9. 如果题目或选项需要图片，请在“题目图片”或“选项A图片”等列填写可公开访问的 https 图片 URL；没有图片则留空。
10. 不要输出 Markdown 表格，不要输出解释文字，只输出 CSV 内容。

主题/课程：
【在这里填写课程主题】

难度：
【在这里填写年级、考试难度、知识点范围】
```

## 只生成选择题

```text
请根据以下知识点生成 20 道以内的选择题，输出为 ailaeclass 可导入 CSV。

CSV 表头：
题型,题目,题目图片,选项A,选项A图片,选项B,选项B图片,选项C,选项C图片,选项D,选项D图片,答案,分数,答案解析

要求：
- 题型只能使用“单选题”或“多选题”。
- 单选题只有一个正确答案，例如 C。
- 多选题至少两个正确答案，例如 A;D。
- 每道题必须有 4 个选项。
- 答案解析要说明为什么正确选项正确，为什么常见错误选项不对。
- 如果题目适合配图，请在题目图片列放一个可公开访问的 https 图片 URL；不确定图片 URL 时留空。
- 只输出 CSV，不要输出其他说明。

知识点：
【粘贴知识点】
```

## 生成带图片题

```text
请生成一份带图片链接的考试题 CSV，用于导入 ailaeclass。

CSV 表头：
题型,题目,题目图片,选项A,选项A图片,选项B,选项B图片,选项C,选项C图片,选项D,选项D图片,答案,分数,答案解析

要求：
- 每次 10 道以内，方便检查图片是否正确。
- 题目图片、选项图片必须是可以直接打开的 https 图片 URL。
- 如果找不到可靠图片 URL，请对应图片列留空，不要编造不存在的链接。
- 题目可以包含“观察图片并回答”。
- 单选题答案写 A/B/C/D，多选题答案写 A;C，判断题答案写 对/错。
- 只输出 CSV 内容。

主题：
【例如：无人机飞行安全、地图识读、植物结构、几何图形等】
```

## 生成无人机考试题

```text
请为无人机培训课程生成 ailaeclass 可导入 CSV。

CSV 表头：
题型,题目,题目图片,选项A,选项A图片,选项B,选项B图片,选项C,选项C图片,选项D,选项D图片,答案,分数,答案解析

要求：
- 总数 20 道以内。
- 覆盖题型：单选题、多选题、判断题、问答题。
- 内容包括：飞行安全、八字飞行、航线偏差、风速影响、电池检查、返航高度、禁飞区、姿态控制。
- 选择题每题 4 个选项。
- 多选题答案用 A;C 这种格式。
- 问答题写出评分参考点。
- 图片列可以留空；如果使用图片，必须填可访问的 https URL。
- 只输出 CSV。
```

## 导入前检查清单

- CSV 第一行是表头，不要使用 Markdown 表格。
- 每次导入 20 道以内。
- 答案列不要写“正确答案是 C”，只写 `C` 或 `A;C`。
- 图片列必须是可访问的 URL，本地图片文件请导入后在编辑器里点击 Add image 上传。
- 导入后先看预览，确认题型、题目、答案、解析和图片都正确，再点击导入。
